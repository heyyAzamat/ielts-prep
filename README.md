# Слово за словом

Тренажёр 600 слов из *Essential Words for the IELTS*: 10 юнитов по 3 темы, как в книге.

- Карточки в двух режимах: RU (перевод и словосочетания) и EN (английское объяснение).
- Задания с интервальными повторениями: 1, 3, 7, 16 и 35 дней.
- Анимированный ночной сад на главной.

Сайт статический, всё в одном `index.html`, прогресс хранится в браузере.

## Деплой

```bash
npx vercel --prod
```
